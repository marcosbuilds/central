Como a área funciona

Estudar é público. A prova é individual.

O material fica aberto para qualquer pessoa. Quando a etapa de provas existir, cada avaliação será vinculada a um Discord ID e só a Gerência poderá criá-la.

Identidade confirmada

03

Prova controlada

O banco de questões é o mesmo; a ordem pode mudar por tentativa, com prazo e resultado ligados ao Discord ID correto.
